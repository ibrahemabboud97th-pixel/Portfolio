🔗 Connect to GitHub (one time only)

Saving to GitHub needs a key that only you hold. You paste it once; this browser remembers it, so you never repeat this on this device.

  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: portfolio-admin · Expiration: the longest available
  3. Repository access → Only select repositories → Portfolio
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token, copy it, and paste it below
