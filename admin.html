Setup needed

The control panel needs a free Firebase project. Fill the values in config.js, then reload this page.

  1. Create a project at console.firebase.google.com
  2. Add a Web app and copy its config into config.js
  3. Enable Authentication → Google
  4. Create Firestore and paste firestore.rules

Full steps are in SETUP.md.

Control Panel

Sign in with the owner Google account to edit the website content.

Control Panel

First time only: press "Import" so the existing content becomes editable. After that, the site reads everything from the database.
